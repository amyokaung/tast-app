The Android directory in this starter contains the custom native files that must
be overlaid onto an Android project generated by the React Native Community CLI.

If your checkout does not contain a complete React Native-generated android/
directory, generate a clean RN 0.87 project first, then copy this repository's
custom android/app/src/main/cpp and android/app/src/main/java/com/myanmarofflineai
files into it and apply android/gradle.properties.

The repository deliberately does not ship node_modules, Gradle caches, or the
llama.cpp third-party source tree.
